# Caesar Cipher – Java

A Java implementation of the Caesar cipher for encrypting and decrypting text using configurable character shifts.

## Features

- Encrypts and decrypts text using a configurable shift
- Supports uppercase and lowercase letters
- Preserves spaces and non-alphabetic characters
- Handles positive and negative shifts
- Validates command-line input

## Technologies

- Java
- Object-Oriented Programming
- Algorithms

## Usage

The program accepts two command-line arguments:

java Caesar <shift> "<text>"

## Example
### Input: java Caesar 3 "The ships hung in the sky in much the same way that bricks don't."

### Output: Wkh vklsv kxqj lq wkh vnb lq pxfk wkh vdph zdb wkdw eulfnv grq'w.
